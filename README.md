# Java Day 46 - Student Attendance Management System

## Description
A Java-based Student Attendance Management System that registers students, records attendance and calculates attendance percentages.

## Features
- Register new students
- Mark daily attendance
- Display attendance records
- Calculate attendance percentages
- Identify students below 75% attendance
- Save records in a CSV file

## Files
- `Main.java` - Main Java program
- `students.csv` - Student attendance records

## How to Run
Keep both files in the same working directory.

Compile:

`javac Main.java`

Run:

`java Main`

## Concepts Used
- Object-Oriented Programming
- Classes and Objects
- Constructors
- ArrayList
- Methods
- CSV File Handling
- Conditional Statements
